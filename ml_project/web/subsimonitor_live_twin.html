How the twin works

  1. Sense — ESP32 nodes read tilt, vibration and temperature.
  2. Self-calibrate — mutual-consistency checks and drift correction clean each reading.
  3. Extract features — tilt angle, rate of movement, vibration level.
  4. Fuse — node scores combine into one composite risk (70% worst node, 30% mean).
  5. Alert — NORMAL < 33, WARNING < 66, CRITICAL ≥ 66 triggers evacuation guidance.

All values on this page are simulated for demonstration. They do not come from real sensors or a trained model.
